## Stream divergence (exposure is real)

Same `Random.seed!(7)` then `randn(50_000)`:

| | Value |
|---|---|
| Agree prefix | **8188** floats |
| First difference index | **8189** |
| 1.10.0 value | 3.704471584095914 |
| 1.12.6 value | 4.1423760338725355 |

So Julia's default RNG stream is **not** version-stable for long draws — the HSquared mechanism applies here. Short prefixes can match; recovery DGPs that consume thousands of `randn` draws can still land on different datasets across CI legs.

NB2 phylo-style DGP at seed 7 (tree + Λ draw + counts) produced identical `y_sum=817.0` on both Julias in this session — a single seed is not a guarantee.
