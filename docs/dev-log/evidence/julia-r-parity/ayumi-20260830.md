## Independent source review (Rose, Sol/high)

The public Julia bridge and generated R wrapper each select a full coefficient
block before picking one returned row. Julia already accepts a block/name pair;
using it removes definite wasted work without changing the target likelihood.

The sparse LSS fit retains its objective but does not retain its analytic
gradient. Generic profiling consequently falls back to finite differences because
the objective uses Float64 work arrays. Value-only evaluations request fresh sparse
factorizations. The finite-difference optimizer branch lacks the explicit iteration
limits used by the stored-gradient branch. Each bridge inference call also refits
from the payload, including covariance construction. These are source-grounded
cost risks, not measured contributions to Ayumi's timeout.

Generic nuisance profiling currently accepts optimizer output without checking its
convergence or score. Endpoint diagnostics are not fully transported through the R
bridge. Exact-target routing does not repair or certify these separate contracts.

The two previously denied engine files remain untouched: gaussian_sparse_lss.jl
and gaussian_structured.jl. No alternative location is used to bypass that denial.
